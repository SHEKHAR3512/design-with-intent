# Brief 05: Contemporary Print & Typography Biennial

## 1. Product Summary
- **Product Name:** Impressum 2026: International Print & Type Biennial
- **Domain:** Cultural exhibition, arts festival, symposium scheduling
- **Mode:** Create

## 2. Audience & Context
- **Users:** Designers, artists, historians, and cultural attendees.
- **Environment:** High-resolution mobile displays, posters with QR codes, desktop browsers.
- **Mental State:** Seeking inspiration, evaluating speakers, purchasing exhibition tickets.

## 3. Primary Task
Explore exhibition themes, browse keynote speaker sessions, and purchase timed-entry passes for festival installations.

## 4. Key Invariant Constraints
- Must avoid generic corporate SaaS aesthetics (no generic blue/purple pill buttons or stock rounded card grids).
- Express visual character derived from physical print culture (letterpress, ink density, bold typography, tactile grid structures).
- Must maintain full readability and accessibility despite creative artistic typography.

## 5. Required Interface States
- **Hero & Curatorial Statement:** Bold typographical statement celebrating physical printcraft.
- **Session Schedule:** Multi-track timetable with stage locations, speaker bios, and real-time seat availability.
- **Ticketing Drawer / Modal:** Clear pricing tiers (Standard, Student, Patron pass) with total calculation.
- **Sold Out Session:** Clear visual indicator with overflow waitlist signup.

## 6. Acceptance Criteria
- [ ] Typography demonstrates deliberate voice and hierarchy without sacrificing WCAG 2.2 AA contrast.
- [ ] Schedule matrix provides responsive mobile view (vertical chronological stream) below 768px.
- [ ] Interactive elements maintain prominent keyboard focus outlines.
