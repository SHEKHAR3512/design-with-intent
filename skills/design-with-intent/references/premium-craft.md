# Premium interface craft

Focused adaptation of [Emil Kowalski's Apple design guidance](https://github.com/emilkowalski/skills/tree/2d228630ba1446365f614a108cb8252f1feda202/skills/apple-design), reviewed 2026-10-18; see [sources](sources.md). DWI adds product-specific acceptance checks. No Apple affiliation or endorsement is implied.

Premium quality comes from clear priorities and reliable details. Preserve the user's brand. An expressive cultural site and a quiet professional tool can both meet this standard.

## Make the product recognizable

Use actual content to determine composition: a comparison tool should foreground the comparison; a photographer's portfolio should foreground the work. Establish one dominant focal point and a clear next action. Avoid filling a template with unrelated hero copy, badges, statistics, and identical cards. If removing the logo makes the page interchangeable, improve its information structure and authentic detail before adding effects.

## Refine the visual system

Choose type size, weight, tracking, and leading together. Inspect real headings at narrow widths; do not tighten body tracking to mimic a display headline. Use a deliberate text measure, responsive spacing, and aligned baselines. System fonts are a useful available default, not a universal brand requirement.

Group by spacing before adding containers. Use surface contrast and subtle depth when they clarify hierarchy. Reserve translucent chrome for content that actually passes underneath it; provide solid fallbacks and verify text contrast over its worst background. Avoid large animated blurs that compromise responsiveness.

## Finish the interaction

Controls need specific labels, visible focus, readable disabled states, immediate feedback, and recovery from errors. Respect touch, keyboard, zoom, and text enlargement. Use motion to preserve continuity without withholding control. Read [motion](motion.md) when implementing or reviewing transitions.

## DWI acceptance exercise

Run the main flow with real content, a long title, no results, and a failed request. At desktop and mobile sizes, identify the first thing a user sees and the next action they can take. Inspect alignment, line wraps, image crops, and focus treatment. Explain one intentional detail that belongs to this product. Record evidence and fix observed problems; do not call a design premium solely because it uses whitespace or glass.
