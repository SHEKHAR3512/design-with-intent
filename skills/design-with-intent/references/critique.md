# Visual critique and refinement

Adapted from Owl-Listener/designer-skills, visual-critique/commands/critique-screen.md (MIT, copyright 2026 MC Dean). See ../licenses/Owl-Listener-MIT.txt. DWI additions: before/after evidence, mode-sensitive action, and no numerical taste score.

Inspect the actual rendered screen when available. Source-only assessment must say so. Review these areas together:

| Area | Evidence to examine | Useful correction |
| --- | --- | --- |
| Hierarchy | First focal point, primary action, competing headings | Reweight and regroup content by task priority |
| Identity | Product content, explicit brand constraints, distinctive detail | Give real subject matter an appropriate visual role |
| Composition | Alignment, proportions, visual weight, grouping | Change the structure causing the imbalance |
| Typography | Roles, measure, wrap, numerals, fallback fonts | Establish a readable, consistent type hierarchy |
| Color | Actual role pairings, action/status distinction, emphasis | Adjust semantic tokens and verified pairings |
| Affordance | Visible controls, states, focus, feedback | Make actions and results understandable |
| Density | Scanning cost, repetition, missing context | Group related information and remove redundancy |

For each finding, record location, observed issue, user impact, suggested change, and evidence. Distinguish a reproducible failure (clipped primary button) from a judgment (too much visual competition). Prioritize blocked tasks and accessibility barriers, then weak hierarchy or identity, then polish. Do not turn a subjective impression into a fabricated percentage or score.

In redesign mode, compare matching before/after screenshots and the change contract. In repair mode, judge whether the specific defect is resolved without unwanted broader change. In audit mode, report findings without editing code.

A useful final statement is “The availability matrix now dominates the screen; pricing is adjacent to the selected date; mobile preserves the same reading order.” “More modern and premium” is not evidence.
